## Status

This endpoint is not documented as a public API because the current backend document-detail handler is not implemented end to end.

Use these supported endpoints instead:

- `GET /api/v1/documents` to list documents that have extraction records
- `GET /api/v1/data/extractions?document_id={document_id}` to inspect extraction results for a document
