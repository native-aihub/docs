---
title: "List API Keys"
description: "List all API keys for your account"
---

## Endpoint

```
GET https://api.documind.cloud/api/v1/auth/api-keys
```

## Authentication

Requires `api_keys:read` scope.

## Response

```json
[
  {
    "id": "key-id",
    "name": "Production Key",
    "description": "Production automation",
    "prefix": "abc12345",
    "scopes": ["extractions:read", "extractions:write"],
    "is_active": true,
    "is_revoked": false,
    "project_name": "Invoices",
    "expires_at": null,
    "last_used_at": null,
    "revoked_at": null,
    "created_at": "2026-06-02T10:00:00Z",
    "updated_at": "2026-06-02T10:00:00Z"
  }
]
```

<Note>
Full API keys are never returned in list responses, only the prefix.
</Note>
