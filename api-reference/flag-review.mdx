---
title: "Flag for Review"
description: "Manually flag an extraction for review"
---

## Endpoint

```
PUT https://api.documind.cloud/api/v1/data/extractions/{extraction_id}/flag-for-review
```

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `extraction_id` | string (UUID) | Yes | ID of the extraction |

## Request Body

```json
{
  "needs_review": true
}
```

## Response

```json
{
  "status": "success"
}
```

Managed terminal decisions cannot be cleared or reopened by flagging. Unmanaged documents keep the existing legacy reflagging workflow, even when their project later opts in. A new intentional processing attempt requires a new document identity. See [Review Decisions](/api/review/understanding-reviews).
