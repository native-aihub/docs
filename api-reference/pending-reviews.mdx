---
title: "List Pending Reviews"
description: "List extractions waiting for human review"
---

## Endpoint

```
GET https://api.documind.cloud/api/v1/pending-reviews
```

## Authentication

Requires `extractions:read` scope.

## Response

```json
[
  {
    "id": "extraction-id",
    "document_id": "document-id",
    "user_id": "user-id",
    "filename": "invoice.pdf",
    "created_at": "2026-06-02T10:30:00Z",
    "updated_at": "2026-06-02T10:30:00Z",
    "status": "completed",
    "review_status": "pending",
    "review_requested_at": "2026-06-02T10:30:00Z",
    "review_decided_at": null,
    "review_reason_code": null,
    "review_comment": null,
    "review_decision_id": null
  }
]
```

## Example

```python
response = requests.get(
    "https://api.documind.cloud/api/v1/pending-reviews",
    headers={"X-API-Key": API_KEY}
)

pending_reviews = response.json()
```

Use `GET /api/v1/data/extractions/{extraction_id}` for full extraction details.

This queue includes managed `review_status=pending` documents and unmanaged legacy `needs_review=true,is_reviewed=false` documents. The `review_status=pending` history filter provides this same combined queue with accurate pagination. A missing queue item is not proof of approval; read its [current state](/api-reference/get-review). Rejected and expired documents remain in history.
